# 詳細設計書 (v2): マルチローカルLLM ベンチ & 多段チューニング研究基盤

対応上位文書: `要件定義 v2`, `基本設計書 v2`
目的: 実装段階でブレを防ぎ、FR/NFR へのトレーサビリティを確保するためのクラス/関数/データ/アルゴリズム/設定/テスト仕様を定義。

---
## 1. 設計方針 / 原則
1. Protocol-first: ランタイム / PromptAdapter / TuningStage を Python Protocol で抽象化し後方互換を確保。
2. Configuration as Experiment (Notebook 版): 外部 YAML を廃止し Notebook Parameter Block (大文字定数集合) を正規化 JSON→sha256 した `config_hash` で再現性を担保。
3. Fail Fast: Manifest ハッシュ/ライセンス不一致は初期化段階で停止。
4. Streaming + Incremental Validation: JSON/構造出力はストリーミング中に拘束検証。
5. Minimal Mandatory Dependencies: 初期 M1 は transformers + pyyaml + fastapi + jinja2 のみに近い形、チューニング系は extras。
6. Deterministic Logging: 乱数種/環境要素を run header レコードに集約。

## 3. コア型定義 (拡張版) 2025-10-09 更新
更新概要:
- Message ロールを tool/function まで拡張し将来の function calling / action injection に備える。
- Tokenizer / TokenCounter 抽象を追加し Runner 間で一貫した token counting を提供 (再現性/比較指標統一)。
- Feature Capability 列挙を導入し非対応機能指定時の degrade policy を明確化。

```python
from __future__ import annotations
from typing import Protocol, List, Dict, Any, Optional, Iterable, Tuple, Literal, TypedDict, Callable
from dataclasses import dataclass

Role = Literal['system','user','assistant','tool','function']

@dataclass
class Message:
  role: Role
  content: str
  name: Optional[str] = None  # tool/function 名など
  metadata: Optional[Dict[str, Any]] = None  # source, timestamp, action_result など

@dataclass
class GenerationParams:
    temperature: float = 0.6
    top_p: float = 0.9
    top_k: Optional[int] = None
    repetition_penalty: float = 1.0
    max_new_tokens: int = 512
    stop: Optional[List[str]] = None
    grammar: Optional[str] = None
    json_mode: bool = False

class StreamChunk(TypedDict):
    text: str
    done: bool
    tokens: int
    latency_ms: float

class StructuredAction(TypedDict, total=False):
    function: str
    arguments: Dict[str, Any]
    confidence: float
    rationale: str
    risk: Literal['low','medium','high']

class StructuredActions(TypedDict):
    actions: List[StructuredAction]

# ---- Tokenization / Counting 抽象 ----
class CanonicalTokenizer(Protocol):
  """モデルファミリに結び付く正準トークナイザ。内部で HF / sentencepiece / 変換を吸収。"""
  def encode(self, text: str) -> List[int]: ...
  def decode(self, ids: List[int]) -> str: ...

class TokenCounter(Protocol):
  """メッセージ列に対する token 集計と budget trimming 戦略を統一。"""
  def count_messages(self, messages: List[Message]) -> int: ...
  def trim_to_budget(self, messages: List[Message], max_tokens: int) -> List[Message]: ...

@dataclass
class TokenizerMeta:
  name: str
  vocab_size: int
  files: Dict[str, str]  # filename -> sha256
  bos_token_id: Optional[int] = None
  eos_token_id: Optional[int] = None

class TokenizerRegistry(Protocol):
  def get(self, model_family: str) -> CanonicalTokenizer: ...
  def meta(self, model_family: str) -> TokenizerMeta: ...

# ---- Action Execution (function / tool 呼出拡張) ----
class ActionExecutor(Protocol):
  """StructuredActions の各 action を検証し副作用を実行 (将来拡張)。"""
  def validate(self, action: StructuredAction) -> bool: ...
  def execute(self, action: StructuredAction) -> Dict[str, Any]: ...

@dataclass
class ActionResult:
  action: StructuredAction
  success: bool
  output: Optional[Dict[str, Any]] = None
  error: Optional[str] = None

@dataclass
class ModelInfo:
    model_id: str
    variant: str
    runner: str
    context_length: int
    quant_format: Optional[str] = None
    size_b: Optional[int] = None

@dataclass
class RouteDecision:
    model: ModelInfo
    reason: str
    confidence: float
    fallback_used: bool = False

class GenerationResult(TypedDict):
    text: str
    actions: StructuredActions
    metrics: Dict[str, Any]
```

## 4. ランナー層設計 (messages 対応 & Capability 宣言 2025-10-09 追記)
### 4.1 BaseRunner Protocol
```python
Feature = Literal['grammar','json_mode','lora','stream','actions']

class BaseRunner(Protocol):
  def load(self) -> None: ...
  def generate(self, messages: List[Message] | str, params: GenerationParams) -> str: ...
  def stream(self, messages: List[Message] | str, params: GenerationParams) -> Iterable[StreamChunk]: ...
  def tokenize(self, text: str) -> List[int]: ...  # 互換のため残置 (内部最適化用)
  def model_info(self) -> ModelInfo: ...
  def supports(self, feature: Feature) -> bool: ...  # capability 宣言
```
互換性: 旧 API (prompt: str) をそのまま渡すと単一ターン扱い。PromptAdapter の外で multi-turn を直接扱いたい場合は messages を渡す。

### 4.2 Capability Degrade Policy
要求された feature が `supports()` で False の場合の挙動:
| feature | degrade 動作 | ログレベル | 代替 |
|---------|--------------|------------|------|
| grammar | grammar 無視 / json_mode なら Guard の post-hoc 修復 | WARNING | JsonStreamGuard リトライ |
| json_mode | strict=False: 通常生成 + Guard; strict=True: CapabilityMismatchError | WARNING/ERROR | - |
| lora | adapter 適用スキップ | WARNING | base 推論 |
| stream | 全文生成後一括 chunk 1 回 | INFO | - |
| actions | StructuredActions 抽出スキップ | INFO | - |

CLI などの上位層は `--capability-strict` を指定で ERROR に昇格可能とする。
### 4.2 実装方針
- TransformersRunner: accelerate + bfloat16 / 4bit (bitsandbytes) 判定。
- VLLMRunner: 連続バッチング (future: queue) — stream() は yield chunk。
- LlamaCppRunner: grammar サポート (json_mode) → grammar 文字列を渡す。
- ExLlamaV2Runner: GPTQ/EXL2 変換済み重みロード + paged KV。
### 4.3 Variant 解決
`QuantVariantRegistry.resolve(model_id, variant_name) -> VariantMeta` (path, hash, format, bits, runner_hint, tokenizer_ref)。
tokenizer_ref により Variant が base family と異なる語彙を持つ場合でも CanonicalTokenizer を選択可能。差異が 1% 超の場合 WARNING ログ。

class PromptContext(TypedDict):

## 6. ルーティング & 信頼度計算
### 6.1 スコア式 (初期簡易)
```
confidence = w_json*json_valid_flag + w_len*length_ratio_penalty + w_rep*repetition_penalty + w_struct*struct_valid_rate
```
`length_ratio_penalty = 1 - abs(actual_tokens - expected_range_mid)/expected_range_mid` (0〜1 clamp)
### 6.2 Router API
```python
class ConfidenceRouter:
    def __init__(self, primary: BaseRunner, fallback: Optional[BaseRunner], threshold: float, max_hops: int = 1): ...
    def route_and_generate(self, prompt: str, params: GenerationParams, guard: 'JsonStreamGuard', scorer: 'ConfidenceScorer') -> GenerationResult: ...
```

## 7. ストリーミング JSON ガード
### 7.1 アルゴリズム
1. 文字単位でバッファ追加
2. 中括弧/ブラケットカウンタと文字列リテラル状態追跡
3. `json.loads` トライ (コスト制御: サイズ閾値 / デバウンス間隔)
4. 成功時 schema 検証 → StructuredActions 抽出
5. 不正パターン (`\u0000`, 制御文字, 連続閉じ) を検知でエラー発火 / リトライシグナル
### 7.2 インタフェース
```python
class JsonStreamGuard:
    def __init__(self, schema: Dict[str, Any], debounce_chars: int = 64): ...
    def feed(self, chunk: str) -> Tuple[Optional[StructuredActions], Optional[str]]: ...
    def reset(self) -> None: ...
```

## 8. Composite Score 計算
```python
class CompositeScorer:
    def __init__(self, weights: Dict[str,float]): ...
    def normalize(self, metrics: Dict[str, float], norms: Dict[str, Tuple[float,float]]) -> Dict[str, float]: ...  # (min,max)
    def compute(self, metrics: Dict[str,float]) -> float: ...
```
デフォルト: `score = (win_rate*0.5 + json_valid_rate*0.2 + structured_accuracy*0.3) / max(latency_norm*cost_coef, 1e-6)`。

### 8.1 正規化参照 (composite_norms.yaml)
`configs/composite_norms.yaml` にメトリクスごとの (min,max) もしくは reference_model を記録。初期化コマンド `capture_baseline.py` が小規模ベースモデルで採取。 drift > 10% で再採取を促す WARNING。

## 14. エラーハンドリング & リトライポリシ
| ケース | 対応 | 最大回数 |
|--------|------|----------|
| JSON invalid | incremental 修復 → 再サンプル | 2 |
| Fallback trigger | 上位モデル再生成 | 1 hop |
| Judge API 429 | backoff (1s,2s,4s) | 3 |
| Hash mismatch | 即 abort | 0 |
| License violation | abort (soft=警告, hard=停止) | 0 |

### 14.1 例外階層 (追記)
```python
class GenerationError(Exception): ...
class JsonValidationError(GenerationError): ...
class CapabilityMismatchError(GenerationError): ...
class RetryBudgetExceeded(GenerationError): ...
class ManifestIntegrityError(Exception): ...
```
ErrorPolicy は捕捉対象を限定し再試行可能な例外のみ再サンプル。CapabilityMismatchError は strict モードで即停止。

## 21. リスク & 対応 (詳細)
| リスク | 詳細 | 対応 |
|--------|------|------|
| メトリクス揺らぎ | Colab 不安定性能 | 三回平均 + outlier 除外 (IQR) |
| Judge コスト | 大量ペア | サンプリング & early stop (統計信頼幅) |

| ステージ肥大 | チューニング pipeline 複雑化 | stage 明示 & 中間成果物 prune |
| ログサイズ | 長期実験で肥大 | gzip 圧縮 + メトリクスのみ抽出 CSV |
